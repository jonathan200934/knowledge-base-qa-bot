# Returns and Exchanges FAQ

## Return Window

Most items can be returned within 30 days after delivery if they are unused, undamaged, and include original packaging.

## Exchange Process

Customers can request an exchange from Order History. Exchanges are shipped after the original item is received and inspected.

## Return Shipping

Return shipping is free for defective or incorrect items. Customers pay return shipping for size, color, or preference changes.

## Store Credit

Customers may choose store credit instead of a refund. Store credit is issued faster and can be used on future orders.
