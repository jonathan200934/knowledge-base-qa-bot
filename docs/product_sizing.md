# Product Sizing Guide

## Size Charts

Each product page includes a size chart. Customers should compare body measurements to the chart before ordering.

## Between Sizes

If a customer is between sizes, choose the larger size for a relaxed fit and the smaller size for a fitted look.

## Measurement Tips

Use a soft measuring tape and measure over lightweight clothing. Product dimensions can vary slightly by material and style.

## Size Exchange

Size exchanges follow the standard exchange process if inventory is available and the item is eligible for return.
